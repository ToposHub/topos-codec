# ADR-C049：LP 编码器策略——P 白编预检门（残差 MAD）与全零残差精确跳过

日期：2026-09-14 · 状态：**已采纳**
关联：ADR-C047（zero-motion IP-2）、ADR-C048（V7-R3 载体）、
V9 计划 §3.6（P≥I 回退定义）、gate review §5.3/§5.4/§5.5（实测依据）

## 1. 背景

实时化（gate review §5.3）后复查（§5.4）：2K 全回退层慢于 4K 的主因
之一是 **P 白编**——「P_size ≥ last_I_size → 弃 P 改编 I」必须先编完
P 才知道尺寸，pan_2k/texture_2k 每帧白编浪费 12.4~12.6ms（~40%）。
另有两项无语义的固定开销：packet_bound 包缓冲每帧 tc_alloc/free（大块
mmap 反复建页/回收）、全零残差仍做自解码+重建。

## 2. 决定

**D1（P 白编预检门，编码器策略）**：残差合成时顺带全帧 |cur−ref| 归约
（整数求和，行带并行、线程数无关）；**MAD ≥ 1<<(bit_depth−6)**（≈满幅
1.56%；bd10=16）时跳过 P 尝试直编 I。校准依据（§5.4 探针，qp72）：
P 胜层全帧 MAD ≤5.5（static 1.2~1.5 / handheld 1.8~4.6 / broll 2.8~5.5 /
cut ≤3.8），全回退层 ≥32.5（texture）与 60~71（pan）、切镜帧 79.9——
门槛 16 居间隙，对两侧 ≥2× 边际。误跳过（MAD 高但 P 本可胜）只损失
码率效率（发出的 I ≤ 本会发出的 P），不损失正确性：I 恒合法、重置漂移。

**D2（产物逐字节不变性质）**：门控直编 I 与 P≥I 回退产出的 I 包**逐字
节相同**（同 cfg 同输入同编码器）——golden_v9 F3 / golden_v73 F3 / 全部
既有 golden SHA 零变化；新增回归测试钉死「门控 I ≡ 强制 I」
（test_v9_codec）。

**D3（全零残差精确跳过）**：X≡0 ⇒ 量化不动点 X′≡0 ⇒ recon =
clip(ref + 0 − mid) = ref 逐位成立（ref 恒在 [0,maxv]）→ 编码器跳过
recon 自解码与重建，参考不推进即重建。零漂锚（test_v9_codec 重复帧、
golden_v9 F2 d2==d1）复核该路径。

**D4（包缓冲 ctx 常驻）**：P/I 候选包缓冲改 ctx 内 grow-only（cap 由
cfg 唯一确定，实际只分配一次），close 统一释放；消除每帧 2×
tc_alloc(packet_bound) 的建页/回收。

**D5（不改变格式与解码端）**：D1~D3 全部是编码器侧策略/内部优化——
解码端可接受的 I/P 序列不变、包格式不变、cfg 域不变；判定规则仍确定性、
线程无关（整数归约）。V9/V7-R3 双载体同享（同一 gop_context 代码）。

## 3. 被否备选

- **按 P 包尺寸上界截断/二次编码**：改变包格式语义，否。
- **MAD 门槛做成 cfg 可调**：策略面无产品需求，先冻结常量（校准数据
  登记于 gate review §5.4），需要时再立 ADR。
- **feed 侧零残差检测**：需解码后扫描 scratch（~1ms）省重建（~3ms），
  收益比不划算，不做。

## 4. 影响

- `gop_context.c`：残差 band 任务加 sad/nz 归约；encode_frame 门控 +
  零残差跳过 + 缓冲常驻；feed I 输出拷贝行带并行。
- 契约文档：`topos_codec.h` encode_frame 注释（策略两条）。
- 实测（gate review §5.5）：2K 全回退层 42.7→64.7 / 29.8→60.3 fps；
  4K 49.7~57.7→54.4~58.8 fps；码率逐字节不变。
