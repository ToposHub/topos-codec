# ADR-C041：rANS 解码交错多状态可行性评估（负结果——解码符号环定性为已达平台）

- 状态：**评估完结，双候选均 NO-GO，零代码入库**（2026-09-11）
- 关联：docs/codec/topos_decode_scan_opt_2026-09-11.md（前一批负结果）、
  ADR-C034/036（rans/rans2 位流）、ADR-C038（产品默认）
- 工具/证据：`tools/bench_rans_ilv_dump.py`（符号流提取）、
  `tools/bench_rans_ilv.c`（原型基准，链接生产 `rans.c` 基元）、
  本 ADR 内嵌系统级 A/B 数据

## 1. 问题与候选

产品目标轴：解码速度（2K 高码率档同码率 0.45~0.70× ProRes）。剖析定位
rans2 符号循环占解码 45-69%。上批（scan 微优化）两个候选负结果后，
本批评估结构性候选 **交错 rANS 多状态**（ryg_rans 经典设计：L 条状态
lane 按逻辑符号序 round-robin，符号/模型/上下文/概率全同 → 压缩率
不变，只放宽状态链深度）——若成立需位流格式扩展（新 entropy 模式，
ADR-C034/036 工程量级）。

## 2. 原型测量（2K 真实素材 1448 万符号，qp62；qp78 复测同结论）

提取器从真实素材 DCT+量化镜像提取逐 slice 符号序列（含 ctx 推导与
后缀 m），原型直接链接生产 `src/entropy/rans.c`（基元逐字节同源，
规避上批"原型复刻基元"的高估教训）。三向自检（源/单态/交错解码
序列+ctx 逐项一致）全过，体积差 ≤0.02%（交错保压缩率的设计验证）。

| 变体 | ns/sym | M sym/s | 相对生产形态 |
|---|---:|---:|---:|
| A：单状态（生产形态模拟） | 7.70 | 129.9 | 1.00× |
| B(2/4/8) 朴素交错（状态在数组，`dec[k%L]`） | 7.6~8.2 | 122~131 | 0.94~1.01× |
| B(4) 寄存器驻留（宏特化 x0..x3 标量） | 6.17 | 162.2 | 0.80× 时间 |
| **A-reg1：单状态寄存器驻留（对照）** | **4.71** | **212.2** | **+63.6%** |

**结论一（交错 NO-GO，判定性）**：寄存器同驻条件下 4-lane 比单状态
**慢 24%**——单状态链的延迟已由乱序引擎重叠消化，多 lane 只摊薄
寄存器与访存流。交错格式立项撤销，不必动位流。

**结论二（寄存器驻留——原型为正、系统反转）**：A→A-reg1 的 +64%
促使实施了生产补丁（两核 `tc_rans_dec_step/suffix` 传引用局部标量，
差分测试钉等价，debug/ASan 79/79 全绿）。系统级 A/B（真实包，
旧/新 dylib 交错 5 轮取中位）：

| 包 | 16t | 1t（TOPOS_SLICE_THREADS=1） |
|---|---:|---:|
| 2K qp78（75KB/帧） | 0.982× | 1.000× |
| 2K qp62（915KB/帧） | **0.949×** | 0.980× |
| 4K qp60（3.4MB/帧） | 0.968× | 0.995× |

**无增益且 16t 净慢 2~5% → 补丁回退**。机理：生产代码传单一已知
局部 `&dec`，编译器 SROA **早已把 x 寄存器化**；原型 A 基线用
`&dec[k%L]` 动态索引模拟"生产形态"，动态寻址的访存往返是**基线
伪影**而非生产成本。补丁只增加代码体（I-cache 压力），故净负。

## 3. 教训（第三次微基准→系统反转，方法论沉淀）

1. 上批：批量重整化微基准等价但 0%、融合 LUT 微基准 +23% → 系统
   −1~−6%（工作集/重建成本反噬）；
2. 本批：+64% 原型 → 系统 −2~5%（**基线模拟失真**：以动态索引模拟
   静态寻址的生产形态，把编译器已消除的成本计入基线）；
3. 沉淀规则：**原型 A 基线必须先与真实产物对账**（本批可用反汇编/
  逐符号耗时对账生产循环是否已寄存器化——事后看 1t 无增益即是信号），
   任何候选晋级前必须过"系统级交错 A/B"门（已为惯例，本批执行）。

## 4. 解码速度轴定性收官

符号环结构性候选全部关闭：交错 NO-GO（本批）、批量重整化/融合 LUT
NO-GO（前批）、寄存器驻留已由编译器完成（本批反证）。剩余项：
SIMD IDCT 残余 ~15%（bit-exact 风险高，ADR-C009 判不启）、NT-store
延期项、16t 内存带宽天花板 7.3×。**解码符号环在本微架构（Skylake
i9-9900K）已达实用平台**；产品档位下解码全配置 ≥2× 实时（P5），
同码率 2K 高码率档 0.45~0.70× ProRes 的差距属该平台的合理落点。
下一代收益窗口在指令集/内存子系统变化或平台迁移（见
docs/metal_backend_migration_and_cross_platform_gpu_plan.md 方向）时重开。
