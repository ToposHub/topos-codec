# ADR-C040：RDO 按 qp 域门控的启用评估（战役遗留项 6 收口）

- 状态：**评估完结——默认关维持，门控启用判定为否**（2026-09-11）
- 关联：优化战役 2026-09-10 遗留项 6、ADR-C038（rans2 产品默认，评估
  前提变化）、ADR-C037（无损平台发现——本评估的关键域）、
  2026-09-04 RDO 钉扎（01a7466d）
- 工具/证据：`tools/bench_rdo_qp.py`、`tools/rdo_qp_eval_2026-09-11.json`（2K）、
  `tools/rdo_qp_eval4k_2026-09-11.json`（4K）

## 1. 评估问题

战役第 5 步：RDO 默认关（proxy 负收益 −0.7~−2.4 dB，hq 分化
+0.04/+0.58），"若未来启用应按 qp 域门控（如 qp≥64 禁用）"。本评估
回答三点：(1) RDO 收益/损失的 qp 域边界在哪；(2) 门控启用能否打过
当前产品默认；(3) 是否值得实施 native qp 门。

前提变化：ADR-C038 起 product 默认熵 = rans2，而 **RDO 仅 V2 VLC 可用**
（`tc_rdo_refine` 率模型 = qp 桶化 VLC 长度表；native 对非 VLC 带
静默不精修）。任何"启用 RDO"的方案都必须先付出 V2 相对 rans2 的
~9% payload 劣势（ADR-C034 实测 −8.7/−9.1%）。

## 2. 测量（bench_rdo_qp.py，2K/4K prores 真实素材，flat，3/8 帧）

**L1 固定 qp R-D 对拍（V2 内，匹配 bytes ΔPSNR；域分离——无损平台
点不参与插值，ADR-C037 教训）**：

| qp 域 | 2K ΔY | 4K ΔY | 判定 |
|---|---:|---:|---|
| ≤48（无损平台） | Δbytes −0.1~+0.8% | +1.3% | 无意义（已无损） |
| 52~56（平台悬崖边） | +16/+3.7 dB* | — | 强正（*悬崖邻域放大） |
| 58~60 | +1.9/+0.8 | +1.4 | 正 |
| 62~76 | −0.1~−1.0（UV +0.3~+1.2） | −0.3~−1.8 | Y 净负（色度换亮度） |
| 80~84 | −1.8~−3.2（UV 转负） | −2.8 | 全面负 |

**收益带 = [无损悬崖边， qp61]**，2K/4K 一致；与战役猜想的门控方向
相反——低 qp 无意义（平台已无损），不是"qp≥64 禁用"而是
"仅 ~52-61 启用"。机制：λ 锚定 qp52（lam_k=0.080·2^((qp−52)/4)），
悬崖边系数多处于量化判定边界，±1 精修以更少位保住近无损表示。

**L2 产品语境（tier 目标同码率，8 帧 + 产品反馈码控）**：

| tier | 2K：默认 rans2 vs V2+RDO | 4K 同 | V2 内 RDO（2K / 4K） |
|---|---:|---:|---:|
| proxy | **−3.02 dB** | −4.73 | −1.55 / −1.65 |
| standard | −1.78 | −1.23 | −0.54 / −0.50 |
| hq | −2.29 | −0.53 | −0.99 / **+0.12** |

六格产品语境全负：tier 落点（qp63~80）坐在 RDO 的 Y 负区，且 V2 的
payload 劣势再叠 ~9%。最好格（4K hq，战役 +0.58 的来源）在 8 帧
同码控口径下缩至 +0.12 dB Y（UV +1.6——预算从 Y 挪给 UV），复合
仍输默认 rans2 ~0.1-0.5 dB。

**L3 编码开销**：+73.5%/+68.9%（qp48，稠密系数）、+34.5%/+55.3%
（qp62）——重于 2026-09-04 记录的 +10~20%。

## 3. 决策

1. **默认关维持；门控启用判定为否。** 无任何产品路径受益：启用 RDO
   须回退 V2 熵，~9% payload 劣势 + 窄收益带 ⟹ 六格 tier 全负。
2. **不实施 native qp 门。** RDO 是显式 opt-in 实验特性（Python 层
   rdo_mode='on' 须显式 entropy_mode='v2'），无产品消费者；加门只
   改变实验用户行为。收益带/损失带数值已钉扎入档，供未来引用。
3. **手动 V2+RDO 用户指引**（入 profiles 注释）：收益带
   qp ∈ [无损悬崖边（flat 422 10bit ≈52-58，素材相关）, 61]；
   qp≥62 Y 净负、≥76 深负、平台域（≤~48）无意义。
4. **若未来产品化**：前置条件是 rans/rans2 熵下的率模型扩展
   （refine 只需相对位差，order-0 近似可承），独立立项；预期收益
   限 [悬崖, 61] 带（+0.8~1.9 dB 量级），并须重估 +35~74% 编码开销。

## 4. 与战役第 5 步记录的差异说明

战役表（3 帧，flat+V2）proxy −0.68/−2.43、hq +0.04/+0.58；本评估
（8 帧 + 产品反馈码控口径）proxy/standard/hq 2K = −1.55/−0.54/−0.99
（V2 内）。差异来源：帧窗、码控轨迹（sized 落点 + 反馈 qp 路径）
与匹配口径。两口径一致的结论：4K hq ≈ 0~+0.6 dB（唯一非负格）、
proxy 深负、产品语境不可用。战役遗留项 6 关闭。
