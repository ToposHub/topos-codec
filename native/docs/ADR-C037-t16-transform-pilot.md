# ADR-C037: 16×16 变换试点——测量与 NO-GO 判定

- 状态：**NO-GO（测量完成，不立项格式扩展）**
- 日期：2026-09-11
- 前置：ADR-C002（8×8 变换冻结）、ADR-C035（rANS 产品默认）、ADR-C036（V7-R2）
- 产出：`src/transform/transform16.{c,h}` + `transform16_tables.h`（试点基础设施，
  单测覆盖）、`tools/gen_transform16_tables.py`、`tools/bench_t16_ab.py`、
  数据 `tools/t16_pilot_2026-09-11.json`（真实素材）/ `tools/t16_smooth_2026-09-11.json`
  （平滑合成）、报告 `docs/codec/topos_t16_pilot_2026-09-11.md`

## 1. 背景与问题

战役遗留清单中「16×16 变换试点」是剩余可验证的最大单项收益候选（文献
3-6%：HEVC/AV1 大变换单项 BD-rate）。试点要回答两个问题：

1. 16×16 方向在本码流的实际素材与工作点上能省多少？
2. 「精确行正交整数」约束（本码流规范性逆变换模型的前提）下能拿到多少？

## 2. 关键前置发现：产品工作点处于无损平台

试点测量时发现（真实编码器实测，flat 矩阵）：**qp≤44（standard qp≤32）
重建逐位无损**——量化误差低于逆变换 >>32 的舍入粒度（qp36 flat 的 Q=16
在 F 域产生的 δF 对像素的贡献 ≈0.19 级，被舍入吸收）。crf/低 qp 导出
路径工作在此平台内。

【勘误 2026-09-11（ADR-C038 批次）】本 ADR 初版曾表述"产品的画质档
（P5 tier qp 域）正处在这个无损/近无损平台"——不准确：sized 档位
编码（ProRes 锚定目标）实测落在 qp54-84（ADR-C032/C035 落点表），
属有损域；无损平台覆盖的是 crf/低 qp 路径。16×16 判定不受影响：
其在 qp54-84 有损域同样净输（真实素材 geo 1.18-1.21，报告 §4.1），
即两个域皆负，NO-GO 加倍成立。

这重构了问题：主域内「画质」轴退化，比的是**无损表示码率**（变换对
系数流的稀疏化/token 效率），而非经典 RD。文献的大变换收益全部来自
低码率有损域——不在产品工作点内。

## 3. 构造：精确正交整数 16×16 的可达形状

「直接整数 DCT-16」不可构造（详证见生成器 docstring 与报告 §2）：
奇数行需要 twiddle 旋转，整数旋转乘积破坏对角 Gram（非标量正交），
Pythagorean 有理角覆盖稀疏且分母连乘爆炸，AV1 式近正交+范数表则改变
本码流的规范性整数逆变换模型。

采用 **Haar2⊗M8 混合**，由 DCT-16 pair-split 恒等式直接导出：
偶行 = M8 行作用在 pair-sum（与真 DCT-16 偶行相关性 0.996-1.000，
即 M8 自身的整数化精度）；奇行 = M8 行作用在 pair-diff（偶频形状对
奇频的保守替代，相关性 0.68-0.90）。精确行正交由构造保证，
E16 = 2·E8（量化域与 8×8 同构）。往返误差 ≤1（W 舍入级）。
浮点正交 DCT-16 作为不可实施的参照上限并行测量。

## 4. 测量设计（零位流成本）

- 三路径：A8（现行，逐位镜像 shipped 量化/token 语义）、B16（混合整数）、
  C16f（浮点 DCT-16 参照）；
- 成本 = 逐 slice 精确 order-0 理想熵 + suffix 位 + 表字节（8×8: 121B/slice
  与现行一致；16×16: 313B，run 字母表扩到 256）；
- Q16 = Q8[u>>1][v>>1]·√(E16E16)/√(E8E8)：像素域量化步逐系数对齐，
  RD 差异纯粹来自变换形状；
- numpy 整数镜像 C 语义（启动时逐位交叉校验，fwd/inv 8×8+16×16 各 32 块）；
- 锚点：真实编码器 payload / A8 理想成本 = rans 1.007/1.015（口径验证）、
  rans2 0.988/0.997（差值即 ADR-C036 上下文增益）；
- 分域对比：无损平台（同 qp 双方皆无损，直接比 bits）与有损段
  （匹配 PSNR 插值，平台点不参与插值）。
- 素材：真实调色样片（1080p ProRes 422 HQ 抽帧，颗粒型）+ 平滑合成
  （文献最好情况）×2 帧；flat/standard 矩阵 × qp 12..80。

## 5. 结果与判定

真实素材（产品域，Y-PSNR 口径；细节见报告 §4）：

| 域 | B16（可实施混合） | C16f（真 DCT-16 参照） |
|---|---|---|
| **无损平台（产品主域）** | **+9.1~11.5% 码率** | +10.3~13.1% 码率 |
| 有损域 | +4~40%（geo 1.18-1.21） | −2~+33%（geo 1.05-1.08） |

平滑合成（最好情况）：无损域 B16 −0.2~−4.9%；有损域 B16 −10~18%、
C16f −15~41%——文献收益只在这里出现，且属产品不覆盖的低码率平滑域。

**判定：NO-GO。** 16×16 在产品实际素材（调色/颗粒型）与实际工作点
（无损/近无损平台）上净损失 9~13%；可实施的混合构造在有损域同样
落后 4~40%；仅不可实施的真 DCT-16 在深有损端（45-59dB、平滑内容）
有 2~17% 优势，不足以立项（需要近正交+范数表的规范性模型变更 +
SIMD 全套，成本远超收益）。

机制（真实素材 qp28 无损档，Y 平面，A8→B16）：DC 族 −72%（68→19KB）、
run 族 −61%（77→30KB）被 **lvl 族 +10.9%**（2372→2631KB）反超——
颗粒能量在 4× 系数上摊薄，近无损档非零 level 更多（nz 94.4%→98.6%，
每 8×8 等效面积 60.4→63.1 个），熵成本上升。这是颗粒素材在无损
表示域的内在代价，与实现无关。

## 6. 遗留与复用

- transform16 核心 + 表 + 单测保留在构建中（零产品风险，未被 codec
  路径引用）；`bench_t16_ab.py` 可对任意 raw fixture 复跑；
- **无损平台发现**对后续码率工作成立的范围（经勘误收窄）：crf/低
  qp 导出路径的优化目标是系数表示熵（稀疏化/token 结构）而非 RD
  折中；sized 档位路径（qp54-84）仍是经典 RD 域；
- 若未来出现低码率平滑内容档（代理分发等），可基于本试点的平滑域
  数据（混合 −10~18%）重新评估，并优先考虑 per-slice 自适应块尺寸
  信令以隔离颗粒区域。
