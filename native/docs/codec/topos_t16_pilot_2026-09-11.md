# 16×16 变换试点测量报告（2026-09-11）

ADR-C037 的数据附件。工具 `tools/bench_t16_ab.py`（复跑方式见文末），
数据 `tools/t16_pilot_2026-09-11.json`（真实素材）、
`tools/t16_smooth_2026-09-11.json`（平滑合成）。

## 1. 测量口径

- **三路径**：A8 = 现行 8×8（量化/token 语义逐位镜像 shipped 实现：
  `tc_quant_block` 的 mag+Q/2、AC 死区 Q/4 整除——有效死区 0.75Q；
  `fill_color_band_tokens` 的 DC 中值预测（每 slice 首行 has_top=0）、
  zigzag 非零 (run,lvl) 对、EOB 计入 run 族、bitlen 类别+suffix）；
  B16 = 混合整数 16×16；C16f = 浮点正交 DCT-16（不可实施参照）。
- **成本**：逐 slice 精确 order-0 理想熵 + suffix((cat−1)/符号) + 表字节
  （8×8: 121B/slice = 29+64+28；16×16: 313B = 29+256+28）。
- **步长对齐**：Q16[u][v] = Q8[u>>1][v>>1]·√(E16uE16v)/√(E8u8E8v8)
  ——逐系数像素域量化步相等，路径间 RD 差异纯来自变换形状。
- **正确性**：numpy 整数镜像与 lib C 实现（含 SIMD 分发的 8×8 公共入口）
  fwd/inv 逐位交叉校验（各 32 随机块）通过后才跑测量。
- **分域**：无损平台（mse=0，双方同 qp 皆无损 → 直接 bits 比）；
  有损段（匹配 Y-PSNR 线性插值 bits；平台哨兵点不参与插值——
  平台内不同 qp 是不同工作点，不可互插）。
- **锚点**（真实编码器 flat rans/rans2 vs A8 理想成本）：
  qp28 rans 1.0074 / rans2 0.9877；qp60 rans 1.0152 / rans2 0.9966。
  rans（order-0）≈ 1.00±0.02 验证口径；rans2 的 −1.2~−2.3% 即
  ADR-C036 上下文增益，两侧同口径下不影响 A/B/C 对比。

## 2. 构造可行性（为什么是混合而不是整数 DCT-16）

精确行正交整数的直接 DCT-16 不可构造：

1. **整数旋转链不可行**：2×2 整数旋转 (a,b;−b,a) 是标量 √(a²+b²) 倍
   正交；嵌入 8×8 的链式乘积 (AB)(AB)ᵀ = A·D_B·Aᵀ 非对角
   （除非各级尺度相同），对角 Gram 破坏。
2. **Pythagorean 有理旋转**精确但角覆盖稀疏（所需 twiddle 11.25°/33.75°
   最近角差 3°+）且分母连乘爆炸（5^7 ≈ 78K → E16 域失控）。
3. **退火搜索**（120 变量 / 56 约束）实测卡在 J≈800（28 个类内点积
   无法同时归零；每类最后一行受 1 维零空间锁死）。
4. **AV1 式近正交 + 范数表**改变本码流「Mᵀ(W⊙)M/2³² 精确整数逆」的
   规范性模型，属更大的格式手术。

混合构造（DCT-16 pair-split 恒等式导出，`tools/gen_transform16_tables.py`）：
偶行 = M8⊗pair-sum（真 DCT-16 偶行，相关性 0.9963-1.0000 = M8 自身
精度）；奇行 = M8⊗pair-diff（保守替代，相关性 0.6843-0.9018）。
E16 = 2·E8，量化域同构；往返误差 ≤1。

## 3. 前置发现：产品工作点的无损平台

真实编码器（flat）实测：qp12/20/28/36/44 → Y-PSNR 哨兵（mse=0），
qp56 起 74.46dB。原因：逆变换的 >>32 舍入粒度吸收了 F 域量化误差
（如 qp36 flat Q=16 → 像素域步长 ≈0.19 级）。standard 矩阵平台到
qp32。crf/低 qp 导出路径工作在此平台内（比的是无损表示码率）。
【勘误】sized 档位编码实测落 qp54-84（ADR-C032/C035），属有损域；
本报告 §4.1 的有损域数据（geo 1.18-1.21）即覆盖该域，判定不变。

### 4.2 平滑合成（最好情况；多频正弦渐变+软圆盘+σ0.7 噪声）

- 无损域：B16 −0.2~−4.9%（flat qp28-44）、C16f −0.3~−7.2%；
- 有损域：B16 geo 0.90（0.82~0.99）；C16f geo 0.74-0.77（0.59~0.88）
  ——文献量级的大变换收益只出现在这个产品不覆盖的域。

### 4.3 机制（真实素材 qp28 flat 无损档，帧 0 Y 平面，理想熵分解）

| 族 | A8 | B16 | Δ |
|---|---|---|---|
| dc | 68KB | 19KB | **−72%**（块数÷4 + 16 像素距离 DC 预测更准） |
| run | 77KB | 30KB | **−61%**（EOB 数÷4 + 长游程压缩好） |
| lvl | 2372KB | 2631KB | **+10.9%**（颗粒能量摊到 4× 系数：nz 94.4%→98.6%，每 8×8 等效面积非零 level 60.4→63.1） |
| 合计 | 2518KB | 2682KB | +6.5%（Y；全平面含表 +9.1%） |

DC/run 的结构性节省被 lvl 的颗粒表示代价反超——后者在无损档是
主导族（>90% bits），与实现质量无关。

## 5. 判定

**NO-GO**（ADR-C037）：真实素材主域净损失 9~13%，混合构造有损域
亦落后；真 DCT-16 仅深有损平滑域有 2~17% 优势且不可精确整数实施。
残留方向（低码率平滑档出现时）优先考虑 per-slice 自适应块尺寸。
