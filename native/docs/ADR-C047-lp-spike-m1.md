# ADR-C047：LP Spike M1 拍板——V9 只做 zero-motion IP-2，P1 运动搜索不做

- 状态：**已采纳**（2026-09-14；批 0 实测拍板）
- 关联：topos_v9_micro_gop_plan_2026-09-13.md §5 批 0（预注册决策门）、
  `docs/codec/topos_lp_spike_2026-09-14.md`（实测报告）、
  `tools/lp_spike_2026-09-14.json`（原始数据）、ADR-C046（版本预算纪律——
  本 ADR 为 V9 major=9 立项的产判据登记点）
- 性质：A-11 类项目级拍板（规划前提被实测推翻后的范围收缩）

## 1. 背景与裁决

V9 计划 §5 批 0 预注册 M1 决策门：「IP-2 中位 ≥20%？zero-motion 是否足够
出货？运动搜索 R 取值？双编码 vs 预判？」，并预注册合法结论集：「收益不足
时 = 只做 zero-motion IP-2 或停止项目」。

批 0 spike（零内核改动，toos CLI 承载 P0 zero-motion 残差伪图模拟，
7 内容层 × 3 锚 qp × 11 帧窗，4K/2K 真实素材 2026-09-14 实测）：

- 全素材库 LT 锚有效中位 ≈6~11%（含回退保底）——**20% 中位门未达**；
- 静止/屏幕/切镜后内容 16~35% 达标；运动内容（横摇/重颗粒/手持）ρ>1，
  双编码择优回退 I 按设计工作（切镜帧实测 ρ=1.35 → 回退）；
- ±4/±8 整像素 MV 探针（全分辨率 SAD 上界口径）：运动层增益 +0~10% 且
  横摇为负（MV 饱和制造 MB 不连续，intra 域预测代价反超）——先验
  「B-roll ρ0.5~0.7（P1 下）」不可达 → **P1 开工线未过**；
- P 编码墙钟 ≈ I（双编码择优成本可接受）；无 DC 量化死区（阈值 Skip 须
  显式 RD 判据）；漂移链 PSNR ≥54 dB 无灾难累积。

**裁决**：按预注册结论集取「**只做 zero-motion IP-2**」——

1. 批 1~3（V9 格式冻结/GOP context/MOV v9）按计划推进；
2. **批 4（有界整数运动估计 P1）取消**——R∈{4,8} 取值问题随之消解；
3. §7 推荐档出货门（IP-2 ≥20% 素材库中位）按批 0 实测预期不达——LP 产品
   档（批 6）以实现后实测评审：不达标则按 §7 纪律保持 experimental/UI
   隐藏，对外话术仅限「静止/屏幕类内容体积优化（20~35%）、全类型不劣于
   Intra +3%」；禁用「≈150 Mbps 同画质」的单一数字宣传（§1.3 非承诺纪律）；
4. 批 7 IP-4 降级为可选评估项（IP-2 未达线时 IP-4 无独立收益来源）。

## 2. 对计划文本的回写义务

- 批 4 标记「数据未达标取消（本 ADR）」；批 7 IP-4 标记降级；
- §7 gate 表追加批 0 实测锚（见报告 §6）；
- 批 2 端到端实现后必须复测 ρ 表（spike 以 intra 通路承载残差伪图，
  与真 inter 通路的预测行为差异是已登记局限）。

## 3. 影响

- 零代码影响（本 ADR 纯决策记录；位流零变化）；
- V9 格式规格不变（§3.1~§3.3 骨架与 zero-motion P 语法照旧）；
- §3.4 预测层级冻结为 P0（zero-MV + exact Skip）；MV 语法预留字段
  按保留零值处理，语义启用须新 ADR + 新 major/minor 预算评审（ADR-C046）。
